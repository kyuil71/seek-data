# K-SEEK · 폰 안에서 도는 문서 검색

실행: https://kyuil71.github.io/seek-data/

- 휴대폰 폴더·파일 또는 구글 드라이브의 PDF / Word(.docx) / PowerPoint(.pptx) / 구글 문서·슬라이드·시트 / TXT / 이미지(OCR)를 색인
- `multilingual-e5-small` 임베딩을 브라우저(기기) 안에서 실행 — 검색어와 문서 내용은 외부로 나가지 않음
- 질의와 의미가 가까운 문장 + 출처(파일·쪽)를 찾아 Excel(검색결과 / 문서별 요약 / 검색 조건)로 저장·공유

처음 한 번: 설정 탭 → "모델 내려받기"(약 120MB). 드라이브는 설정 탭의 안내에 따라 OAuth 클라이언트 ID를 넣고 승인된 원본에 `https://kyuil71.github.io` 등록.
