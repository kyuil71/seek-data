구글 드라이브 연결

클라이언트 ID 만드는 법 (한 번만)
  1. 새 프로젝트 만들기이름은 아무거나 (예: k-seek) 프로젝트 만들기 열기 ↗
  2. Google Drive API 사용 설정위에서 만든 프로젝트가 선택된 상태에서 ‘사용’ 누르기 Drive API 열기 ↗
  3. OAuth 동의 화면(브랜딩)‘시작하기’ → 앱 이름 입력 → 대상: 외부 → 연락처에 본인 Gmail 동의 화면 열기 ↗
  4. 테스트 사용자에 본인 추가대상 → 테스트 사용자 → 본인 Gmail 추가 (안 하면 로그인 거부됨) 대상(테스트 사용자) 열기 ↗
  5. OAuth 클라이언트 ID 만들기유형: 웹 애플리케이션 → 승인된 JavaScript 원본에 아래 주소 추가 클라이언트 만들기 열기 ↗
  6. 클라이언트 ID 붙여넣기만들어진 ‘…apps.googleusercontent.com’ 값을 위 칸에 넣고 저장 클라이언트 목록 열기 ↗
읽기 전용 권한(drive.readonly)만 요청합니다. 구글 로그인 정책상 Chrome 같은 브라우저에서 열었을 때 연결됩니다.
